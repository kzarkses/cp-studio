## 3. The Sequencer JSFX (J/Seq)

### 3.1 Concept (RS §1, §8.3)
Monophonic 16-step sequencer "à la Pigments": 9 lanes, each with its own length (1..16) and speed multiplier
(polyrhythm), per-lane dice and Turing-machine mutation, scale degrees, two free lanes (MOD A/B) as modulation
sources, 16 patterns switchable by MIDI note / program change, an arpeggiator as a third "incoming notes" mode.
Everything in `@block` (no audio touched), events sample-accurate via `midisend` offsets. `ext_noinit = 1` (J/Seq:239).

### 3.3 Internal memory (J/Seq:240-268)
DEG 0 (12 scale degrees), SPDF 16, LENA 32, PCYC 48, POS 64, LMIN 80, LMAX 96, LINT 112, LBOOL 128, PPER 144,
PSPD 160, SPDT 176, RATEB 192, EVQ 256 (64×4 out events), INQ 512 (256×4 incoming), SNAP 1536 (2×16), PC0 1568,
**PATM 4096 (16 patterns × 256)**, PATP 8192 (NPV slider numbers), PDEF 8448 (NPV defaults), ARH 8704 (32 held
in play order), ARS 8736 (sorted), ARK 8768 (128 key-down flags), ARQ 8896 (256×4 arp note queue).
Pattern/arp state is initialised only once (`pt_boot`, J/Seq:526-533): a re-run of @init must not wipe patterns.

### 3.4 Clock and transport (J/Seq:1084-1154, 1156-1196)
- `playing = play_state==1 || play_state==5`. Source `src`: 0 none, 1 transport, 2 own clock.
  `seq_on>0.5 ? ((clk≠2 && playing) ? 1 : (clk≠1 && seq_run>0.5) ? 2 : 0) : 0`.
  → Auto: transport when REAPER plays, own clock (if Run) when stopped. Transport: only while playing.
  Free: own clock only (if Run), ignores the transport.
- Tempo `tb = tempo>1 ? tempo : 120`; `spb_s = srate·60/tb` samples per quarter; block length `blk_b = samplesblock/spb_s` quarters.
- b0 (block start, quarters) = `beat_position` (src 1) or `fb` (own counter, src 2; `fb += blk_b` per block).
- Source change: transport→own (Auto + Run, transport stops) continues seamlessly from the last position;
  any other change → note-off, own clock restarts at 0 (step 1), `seq_reset(b0)`. Jump/loop detection while on
  transport: `|b0 − last_b1| > blk_b/2 + 1e-4` → note-off + reset. Reset also restarts the arp at its 1st note.
- src = 0 → note-off every block. Bypass by REAPER's FX bypass button cuts without note-off (known limit RS §8.9).

### 3.5 The step engine
- Grid: `stepB = RATEB[rate]` (quarters); lane L index at time t: `k_L = floor(t·SPDF[L]/stepB + 1e-6)`;
  **TRIG's speed sets the note grid**: `stepT = stepB / SPDF[0]`. Steps are counted by NUMBER (`k_last`), not by
  comparing block positions. Swing: `tsw(k) = k·stepT + (k odd ? swd : 0)`, `swd = swing·0.005·stepT`.
- Period of a lane of n steps: n (Fwd/Back/Random), `2n−2` for ping-pong (ends not repeated; n<2 → 1).
  Position: Fwd `k mod n`; Back `n−1−(k mod n)`; Ping-pong `i = k mod (2n−2); i<n ? i : 2n−2−i`;
  Random `hash(k,L) mod n` with `hash`: `a = k mod 32768; h = (a·1103 + L·7919 + 12345) mod 32749; h = (h·h + 1013) mod 32749; floor(h/7)`
  → deterministic, a jump/render replays the same order (J/Seq:563-587; Lua mirror S/Sequencer.lua:2022-2039).
- Lane cycle `c = floor(k/period)`; when c increases → mutation (§3.7). A change of length/speed/direction
  re-syncs the cycle without mutating; the cycle never goes backwards.
- **fire(k, o)** (J/Seq:961-1006), for every TRIG step whose swung date falls in the block (≤64 per block),
  offset `o = round((tsw(k) − b0)·spb_s)` clamped to the block:
  1. every lane ticks at the UNSWUNG date `k·stepT` (swing moves the note, not the melody);
  2. a pending note-off due before o is sent;
  3. arp mode: received notes up to offset o are applied first (a chord on the step's date counts);
  4. `on = TRIG[pos] > 0.5`, then `on = rand(100) < CHANCE[pos]`; arp with nothing held → silence;
  5. pitch (non-arp): `nt = tonic + deg_semi(PITCH) + 12·OCT + transp + in_tr`; arp: `nt = ar_note(round(PITCH)) + 12·OCT + transp` (scale & tonic unused); clamp 0..127;
     `deg_semi(d)`: `d = round(d); oc = floor(d/N); oc·12 + DEG[d − oc·N]` (N = number of degrees of the scale);
  6. vel = clamp(round(VEL),1,127); gate length `gt = floor(GATE%·0.01·dist) − 1`, `dist = (tsw(k+1) − tsw(k))·spb_s`, min 16 samples (at 100 % the note ends 1 sample before the next);
  7. SLIDE on → no note-off scheduled (`off_at = −1`), the next note-on is sent BEFORE the previous note-off (mono legato); same pitch → nothing re-sent (note continues). A non-playing step after a sliding note kills it.
  Note-on `0x90+chan`, note-off `0x80+ch` vel 0. **Note-off is guaranteed** on every cut (stop, jump, mode change, OFF).
- Scales (S/Sequencer.lua:244-282, mask generated from the SG table, J/Seq:495-512): index 0..15 = Chromatic 4095,
  Major 2741, Minor 1453, Dorian 1709, Phrygian 1451, Lydian 2773, Mixolydian 1717, Locrian 1387, Harmonic Minor 2477,
  Melodic Minor 2733, Major Pentatonic 661, Minor Pentatonic 1193, Blues 1257, Whole Tone 1365, Fifths 129, Octaves 1
  (bit k = k semitones above the tonic). = the SG list WITHOUT "Off".
- Incoming MIDI (J/Seq:1024-1065): pattern notes (`pbase ≤ note < pbase+16`, note-on vel>0 requests pattern
  `note−pbase`; note-offs on them swallowed) and program change 0..15 → pattern request (both only when
  `seq_pnote ≠ Off`; Off = they pass). Else by `seq_notein`: **Thru** → passed through, merged with generated notes
  in date order; **Transpose** → note-on sets `in_tr = note − 60` (held after release; notes not passed);
  **Arp** → notes queued for the arp (not passed). Non-note messages always pass. Changing the mode clears the chord.

### 3.6 Patterns (J/Seq:715-844, 1095-1133, 1261-1305; S/Sequencer.lua:113-166, 1762-1937)
- **The sliders ARE the current pattern**; JSFX memory PATM holds the 16. A pattern = NPV = 207 values, order
  `PAT_P` (S/Sequencer.lua:405-419): p3 rate, p4 swing, p5 dir, p6 root, p7 scale, p8 oct, p9 transp, p20..p217
  (all 9 lanes incl. len/speed/mut/dice/lo/hi), p227 arp order, p228 arp octaves. NOT in a pattern: on, run, clock,
  channel, notein, latch, pattern settings (pnote/pq), wires ("the patching, not the music").
- Switching (`pt_apply(n)`, inside the JSFX): save current into PATM; if n defined → load into sliders (rev++,
  `sliderchange(-1)`), **if never visited → it is born a COPY of the one being left**; `pt_cur = n`. Clear = defaults
  (stays defined). Reset-all (Init) = 16 × defaults, mask = 1, cur = 0.
- Change point `pt_when(t)`: Now → immediate; Next Beat g=1, Next Bar g=4 (quarters, 4/4), Pattern End
  `g = period(TRIG)·stepT`; date `ceil(t/g − 0.001)·g`. Takes effect at the HEAD of the block containing its date
  (a step on that date already plays it). Transport stopped → immediate. Loop back → next grid point.
- **Request protocol** (`seq_preq`, Lua side S/Sequencer.lua:1810-1828): `nonce = (floor(cur/4096)+1) % 1024` (0→1),
  write `nonce·4096 + op·256 + (arg & 255)`. ops: 1 SELECT(arg=n), 2 COPY(arg = a·16 + b), 3 CLEAR(n), 4 ADOPT inbox,
  5 PUBLISH (republish mirror), 6 RESET all. **One request per audio block** (two clicks faster than a block → the
  first is lost). After a `@serialize` load, the first block ADOPTS the stored slider value without executing it; a
  FRESH instance executes its pending request (that's how an upgrade re-adopts its patterns).
- Mirror (JSFX → Lua), base `g = 2097152 + ch·8192`, ch = `seq_pch`: `[g]` token (= seq_ptok), `[g+1]` version
  (incremented LAST), `[g+2]` cur, `[g+3]` mask, `[g+4]` NPV, `[g+5]` pending, `[g+16 + k·256 + i]` value i of each
  DEFINED pattern k (the current one from the sliders). Republished on any change and when the channel changes.
  Lua read (`readPatterns`): retry up to 3× until `[g+1]` is unchanged across the read; returns
  `{cur, mask, s = {[k] = "v,v,…"}}` with `%.10g` values, current from sliders. nil if token mismatch.
- Inbox (Lua → JSFX), `ib = g + 4096`: write values `[ib+16 + k·256 + i]` (missing → defaults), `[ib+2]` cur,
  `[ib+3]` mask|1<<cur, `[ib+4]` NPV, then `[ib] = token` LAST, then request op 4. JSFX adopts only if `gmem[ib] == seq_ptok`.
- Wire (`ensureWire`, S/Sequencer.lua:1781-1808): `seq_pch := fastChannel(track)`; if it changed (duplicated track)
  or token < 1 → new random token. Re-checked once per second.
- `@serialize`: marker 7301, version 1, NPV, cur, mask, then `file_mem` NPV values for each DEFINED pattern
  (current saved from sliders first). A shorter stored pattern takes missing values from defaults.
- Track park string (`encodePat`): `"cur;mask;k=v,v,…;k=v,v,…"`.

### 3.7 Generation (J/Seq:589-636, 1067-1082)
- `roll_step(L, j, a)`: bool lane → with probability a, step := (rand < hi) ? 1 : 0. Value lane → draw
  `r` in [lo,hi] (int: `floor(lo + rand·(hi−lo+1))` capped at hi; float: uniform), `v += (r − v)·a`, round if int,
  clamp to lane min/max.
- Dice of a lane: `a = dice%·0.01`, applied to the steps that PLAY (j < len; steps past the end are kept).
- **Roll request** `seq_roll = nonce·512 + mask` (Lua: `nonce = (floor(cur/512)+1) % 1024`, S/Sequencer.lua:1748-1758):
  each lane with its bit set is diced; rev++. Adopted (not executed) at the first block after load. ROLL ALL = mask 511.
- Mutation (Turing Machine): at each new cycle of lane L, each playing step with probability `mut%` is redrawn with
  a = 1 (full range); rev++. 0 % = frozen loop.
- Mutation/roll are written into the sliders (`slider(p) = v; sliderchange(-1)`); readback beyond the 64th slider
  works (the pattern path relies on it, RS §9.2).

### 3.8 Arpeggiator (J/Seq:875-953, RS §9.3)
- Held set ARH (≤32, play order) + ARS (sorted). Latch counts FINGERS (ARK[128]): with latch on, the first key
  pressed when all fingers were up REPLACES the chord; releasing keeps the chord; turning latch off keeps only keys
  still down. Empty chord → next new note restarts at index 0.
- `ar_note(off)`: `oc = clamp(arpo,1,4)`, `nn = n·oc`, `per = nn>1 ? 2nn−2 : 1`, `i = ar_i mod per`;
  t = Up `ar_i mod nn` | Down `nn−1−(ar_i mod nn)` | Up/Down `i<nn ? i : per−i` | Down/Up `nn−1−(that)` |
  As Played `ar_i mod nn` (on ARH) | Random `floor(rand(nn))`; `t += off` (TONE = PITCH lane value);
  `c = floor(t/n)`; note = `chord[t − c·n] + 12·c`. `ar_i++` per played arp step.
- Arp order and octaves are IN the pattern; latch is not.

### 3.9 Outputs and fast publish (J/Seq:1202-1248)
- Per block: rev, pha/phb, state, moda/modb (current step value, 0.5 when OFF), note, pat/pmask/pnext.
- If `seq_fch` ∈ 1..255: for each 32-sample sub-step k (n = ceil(samplesblock/32) ≤ 256):
  `gmem[ch·4096 + 2064 + k] = line_at(MOD A, end of sub-step)`, `+2320 + k` for MOD B (value as a function of the
  DATE, swing-mapped back to unswung time, current cycle read from a pre-mutation snapshot); stopped → the held
  output value; then header `[0]=n, [1]=32, [2]++`.
- Output MIDI = generated events + Thru/other incoming, merged by offset.

## 4. Sequencer — Lua side (S/Sequencer.lua)

- **The JSFX is the truth, not a Lua state** (mutation writes steps window-closed). The module keeps a cache
  `VALUES[p]` (raw), `OUT`, `POS`; `poll()` once per frame: reads outputs p12..18 and p219..221 every frame,
  full re-read of all 230 sliders when `seq_rev` moves, every 0.5 s, or on instance change — **never during a drag**
  (`Sequencer.dragging`). S/Sequencer.lua:1617-1697.
- Writes: `setRaw(p, v, linked)`: clamp to spec (int/bool rounded) → `TrackFX_SetParam(raw)`, or, if the param is
  under an internal modulation link, `LinkEngine.setInternalBase(tr, idx, p, norm)` (the link baseline). :1726-1743.
- `writeJSFX()` at every init (generated source = slider lines from SPEC + fixed engine + generated tables).
- `create()`: if present → upgrade if needed, `TrackFX_SetEnabled(true)`, `seq_on = 1`; else add at index 0
  (`-1000`), hidden. Invalidates cached FX indices. :1578-1603.
- `ensureUpToDate()`: if `GetNumParams < 230` (and no mouse button down, no capture pass): rewrite file, carry
  settings + FX envelopes (state chunks) + internal links (`param.<p>.plink.*`, `mod.active`, `mod.baseline`) +
  bypass + the 16 patterns (read from mirror BEFORE delete, re-sent to the inbox), delete, re-add at the same index.
- **OFF vs REMOVE** (S/UI.lua:7083-7250): OFF = `seq_on` 0 (pause, instance stays). REMOVE = `capture()` →

### 6.2 Architecture
- **Voice bank**: 8 voices × 128-word records at 8192 (J/SG:516-570): ACT, NOTE, VEL, AGE, HELD, ENV, ST (0 idle,
  1 attack, 2 decay/sustain, 3 release, 4 delay, 5 hold, 6 fade-out), CUR/TGT (semitones from A4, glide lives in CUR),
  HAVE, VG (velocity gain), FIDX (filter base index), per-voice stereo SVF state, 3 osc × (phase L/R, increment L/R,
  noise state L/R, click age), XENV[3] / XST[3] / XDLY[3] (ENV 2..4 per voice), DLY (ENV 1 delay/hold counter),
  QL/QR (osc1 read phase for PM-aware BLEP), sample positions/age/stolen-voice fade.
- **3 oscillators per voice**, each: on, wave (Sine `cos(2πφ)` · Triangle `4φ−1` folded · Square `φ<.5 ? 1 : −1` ·
  Saw `1−2φ` (descending) · Noise `w·(1−color) + brown·color`, brown = one-pole(0.1) of white, L/R decorrelated when
  width>0 · Click = 5 ms white burst, squared linear decay, restarted at each note and each rhythmic tick) or the
  SAMPLE (§6.11); vol; pan; width; pitch. Phases normalized 0..1; increments computed per block.
- **Stereo width**: `fL = f/2^(w/1200)`, `fR = f·2^(w/1200)` (osc_phase_inc, J/SG:903-914).
- **FM** (phase modulation OSC 2 → OSC 1, J/SG:2526-2555): when `zfm > 0`, OSC 2 is computed first (even if OFF;
  then inaudible), OSC 1 is read at phase `φ + fmk·osc2_out` per channel, `fmk = fm²·1.5` turns (`FM_MAX` 1.5).
  fm = 0 → bit-identical to the old render.
- **Mix per voice** → per-voice TPT SVF (if filt_type > 0) → `× ENV × VG` → sum → `× amp × autogain`.
  No other effects (no unison beyond L/R width, no chorus/delay).
- **Polyphony**: `poly` 1..8; `poly < 1.5` = mono. New voice = first free, else OLDEST (`V_AGE`). Note stack 16
  (last-note priority), note-off releases only the voice holding that note (poly).
- **Mono rules** (J/SG:717-770, 2239-2259): legato (`legato && mono && keys held`) → same voice changes pitch only
  (no re-attack, no phase/click reset). Non-legato mono hit → `v_tail`: the sounding voice record is copied to a free
  (or oldest) voice and faded out (state 6, `fade_k = 1 − exp(−dt/0.0015)`, ≈10 ms), voice 0 restarts its envelope
  from ZERO — "every trigger redraws exactly the same path" (Cedric 2026-10-04). Overlapping releases = Voices ≥ 2.
  Poly: a stolen voice's attack starts from its current level (no click).
- **Events** are queued with their sample offset (evq, 64/block) and applied in @sample at their date; a note born
  mid-block gets its pitch/gain immediately (`v_prep(vb, gl_now)`).

### 6.3 Modes
- **Mode boundary** (J/SG:1675-1719): key = (mode>.5) + 2·(midi_mode>.5) + 4·(poly<1.5); on change → all voices
  released (release time), in Continuous voices 1..7 killed, voice 0 pitch reset (CUR=TGT=HAVE=0), note_on = 0,
  manual/keyboard edges re-armed as "already consumed".
- **Continuous** (mode 0): no notes; voice 0 forced active with `ENV = tick_env`: rhythmic on → phase += tick_rate·dt,
  target = phase < duty ? 1 : 0, `tick_env += (target − tick_env)·curve_k`, `curve_k = curve>0.001 ? min(1, dt/(curve·0.1)) : 1`;
  rhythmic off → 1 (drone). Pitch = the oscillators' absolute Hz, unless `cont_note` = Notes AND `kbd_gate` = 1:
  then voice 0 target = kbd_note − 69 (glides; first key "poses"). ENV 2..4 outputs = 0. MIDI not read.
- **Triggered** (mode 1): ENV 1 ADSR per voice. Sources of notes: (a) MIDI only if `midi_mode` = MIDI (note-on, note-off,
  CC120/123 = all off; MIDI re-sent with `midisend`); (b) window keyboard band, always (edge of kbd_gate, note change
  under a held gate = glissando off+on, offset 0, queued before MIDI); (c) `manual_trigger` rising edge →
  `v_start(voice 0, note 69, vel 127)`, falling edge releases voice 0 unless keys are held.
  ⚠ Pitch tracking of the played note applies only when `(mode=Triggered && midi_mode=MIDI)` or Continuous+NOTES
  (`no = … ? V_CUR : 0`, J/SG:949): in Triggered+Manual the keyboard gates notes at the oscillators' base pitch (?)
  — code fact, intentional per comment (it keeps old patches unchanged).
- When neither mode reads MIDI, the JSFX does not call `midirecv`, so MIDI passes through untouched.

### 6.4 Pitch (per voice, per block — `v_prep`, J/SG:937-976, 1956-1961)
```
nbN_0 = 69 + 12·log2(oscN_freq/440) − oscN_fine/100        (semitones, cents removed)
nbN   = nbN_0 + pm_eff[N]                                  (pm slider or fast route)
no    = voice CUR (note−69, glided) if pitch-tracking else 0
m1 = nb1 + no ; if osc1_scale ≥ 1: m1 = snap(m1, scale1, root1)
f1 = 440·2^((m1 − 69 + fine1/100)/12)
oscN (N=2,3): m = rel ? m1 + semiN + pm_eff[N] : nbN + no ; snap with its own scale
fN = 440·2^((m − 69 + (rel ? fine1 + centsN : fineN)/100)/12)
```
`snap(m, sc, rt)`: nearest scale degree, ties → lower (tolerance 1e-6); masks = §3.5 list with index 0 = Off
(SG index 1 = Chromatic). Glide: per block `CUR += (TGT − CUR)·(1 − exp(−samplesblock/(glide·srate)))`
(glide ≤ 0.0005 → immediate); a voice without a previous pitch (`HAVE = 0`) poses without gliding.

### 6.5 Envelopes
- **Durations** (per block, J/SG:1559-1643): `spb = tempo>1 ? 60/tempo : 0.5`; `u = beats(sync)·spb` with
  beats(sync) = {Free 0, 1/16 .25, 1/8 .5, 1/4 1, 1/2 2, 1 bar 4, 2 bars 8, 1/32 .125} (quarters, 4/4).
  Free → slider seconds unchanged. Synced → each stage = `env_steps(t, tmax, lo)·u`, `env_steps = clamp(round(t·16/tmax), lo, 16)`,
  tmax = 2 (attack, decay, delay, hold) or 5 (release), lo = 1 (A/D/R) or 0 (delay/hold). The knob therefore spans
  16 divisions whatever the tempo (panel shows "3 x 1/16"; mirror `SGPanel.envSteps`).
- **ENV 1 (amplitude)**: state 4 delay (integer sample counter) → 1 attack `env += dt/A` (linear, from the current
  level) → at 1: state 5 hold (counter) or 2 → decay `env −= (env − S)·(1 − exp(−5dt/D))`, snaps to S within 0.001
  → note-off: 3 release `env −= env·(1 − exp(−5dt/R))`, voice dies at ≤ 0.001. Zero delay/hold → same path as before
  (no extra sample). `use_adsr` Off → env = held ? 1 : 0.
- **ENV 2..4** (modulation only — never touch gate/filter/mix/voice life): same DAHDSR state machine per voice
  (`V_XENV/V_XST/V_XDLY`), coefficients per block in the global region `XENV` (896: 3 × 8 words: KA, KD, SUS, KR,
  LAST, DLY, HLD), started at each note-on from the current level, released with the voice, cut when the voice dies.
  ⚠ code≠roadmap: RF §21.7 says ENV 2..4 are "global, retriggered by the last note"; the code keeps a PER-VOICE state;
  what is global is the coefficient region and the OUTPUT = **max over active voices**, one value per instrument.
  A per-voice (polyphonic) modulation is still to be decided (recommendation: a per-link "per voice" option, off by default).
- **Outputs** (one block late, J/SG:1819-1828): `env_out` = max over voices of ENV 1 (or tick_env in Continuous);
  `env2_out..env4_out` = max of each extra env (0 in Continuous); `peak_out = min(1, peak)`, peak = max |spl0|,|spl1|
  since the previous block, then `peak ×= 0.7`.

### 6.6 Filter (per voice, J/SG:882-890, 973-975, 2162-2164, 2579-2606)
Table `ftab[0..1024]` = tan(π·fc/srate), fc = 20·2^(i/ft_per_oct), `ft_per_oct = 1024/9.965784`, fc capped at 0.45·srate.
Base index per voice: `(log2(cut/20) + key·(note−69)/12 + fvel·(vel/127 − 1)·4) · ft_per_oct`; per sample
`fi = base + filt_env·6·ft_per_oct·gate + fast_offset`, clamp 0..1024. TPT SVF, `k = 2 − 1.98·res` (Q 0.5..50);
LP = v2, BP = v1, HP = x − k·v1 − v2, Notch = x − k·v1. Off (type 0) = skipped entirely.

### 6.7 Velocity, pan, gain, smoothing
- `VG = 1 − vel_amp·(1 − (vel/127)²)` (attenuates soft notes; 127 → 1).
- Pan (linear): `L = pan ≤ 0 ? 1 : 1 − pan`, `R = pan ≥ 0 ? 1 : 1 + pan`.
- Auto gain: if on and Σ(vol of ON oscs) > 1 → `1/Σ`.
- Volumes, amplitude, FM index, auto gain and pans: per-block linear ramp to the new slider value, then a fixed
  2-pole cascade (`ZTAU` 1.5 ms, `zk = 1 − exp(−1/(ZTAU·srate))`); bit-exact copy when nothing moves.

### 6.8 Fast routes (J/SG:315-358, 983-1085, 1896-1913, 2169-2173)
- `fch` (p99) = channel; up to 8 routes `(dst code, src slot 1..10, amt, ctr)` at p100+4r..p103+4r.
  Slots 1..8 = CP_Mod bank LFOs, **9 = Seq MOD A, 10 = Seq MOD B**.
- Every 32 samples (`FTICK`): `v = gmem[ch·4096 + 16 + (slot−1)·256 + min(k, n−1)]`, n = `gmem[ch·4096]` (0 if stale
  > 4 blocks); `FOFF[code] += amt·(v − ctr)`; linear destination value = `denorm(clamp01(norm(slider) + FOFF))`.
  Cutoff (code 4) works in octaves: `nb = ln(cut/20)/ln(1000)`, offset index `(clamp01(nb+off) − nb)·9.9658·ft_per_oct`,
  ramped over the 32 samples. Volumes/amp/FM ramp over 32 samples; pitch/width/color/pan step at the tick (pitch and
  width recompute each active voice's increments).
- **Codes** = `SoundGenerator.FAST_DST` (S/SoundGenerator.lua:4030; FMIN/FMAX J/SG:330-348), code → p:
  1 p86 osc1_pm, 2 p87 osc2_pm, 3 p88 osc3_pm (±63.5 st), 4 p42 cutoff (log), 5 p43 res, 6 p18 osc1_vol,
  7 p23 osc2_vol, 8 p29 osc3_vol, 9 p4 amplitude, 10 p3 osc1_width, 11 p22, 12 p28 (widths 0..100), 13 p5,
  14 p24, 15 p30 (colors), **16 p38, 17 p39, 18 p40 (pans, since 2026-10-08), 19 p132 (FM index)**.
  ⚠ code≠task/roadmap "15 destinations": 15 originally (RF §21.7 phase 5), now 19 — the hard ceiling of this memory
  layout (tables FOFF/FUSE/FMIN/FMAX have 20 cells). Lua reads the max code an instance knows from the range of
  `fr1_dst` (`fastMaxCode`: 19, 18 or 15).
- Which params become fast routes (LinkEngine planFast): SG params in FAST_DST whose sources are ALL local bank LFOs
  and/or seq 221/222, no modulated depth, ≤ 8 routes total; the native link is removed. Macros, envelopes, global bank → native link.

### 6.9 Window keyboard band (p55..58)
`kbd_gate` is the edge (a click within one block survives), `kbd_note` the pitch (can change under a held gate),
`kbd_vel`. Triggered: notes through the same queue as MIDI (stack, legato, glide, velocity all apply). Continuous:
`kbd_gate` = LATCH (with `cont_note` = Notes, the drone follows kbd_note). After load, the first block reads the
stored gate as "already seen" (no phantom note).

### 6.10 MIDI summary
Input: note on/off, CC 120/123, only in Triggered + MIDI. No pitch bend, no CC mapping, no channel filter (all
channels). Output: everything received is re-sent in that mode; otherwise untouched pass-through.

### 6.11 Sample (J/SG:381-423, 1139-1422, 2064-2149, 2630-2643)
- One sample per generator; each osc chooses Wave or Sample (`oscN_smp`). Level 0 = file as is (interleaved, up to
  `SMP_CAP` 4,194,304 samples ≈ 43 s stereo @48k → status 4 "truncated"), then 4 decimated mip levels (47-tap Kaiser
  half-band) built progressively per block; Hermite 4-point read; level chosen from read rate (crossfade 1.1..1.4).
- Geometry: frames per cycle of root note `smp_k = sr / (440·2^((root−69)/12))`; rate = phase increment·smp_k·dir;
  region `a = min(rs,re)·full`, `b = max(rs,re)·full` (clamped to loaded frames); start `a + start·(b−a)` (from b when
  reversed); loop `[a + ls·(b−a), a + le·(b−a)]`, active if loop on and ≥ 32 frames; crossfade `xf` ms ≤ half loop.
  Fades: note-in 1 ms, region end 2 ms, (re)load 5 ms out/in, stolen voice 2 ms. FM shifts the read position
  (one turn = one period of the root note). Each note restarts at the start point.
- **Mailbox** at `g = smp_ch·4096 + 3072`: Lua writes `[g+1]` token (= smp_tok slider), `[g+2]` length, `[g+8..]`
  path chars (≤ 495), then `[g] = [g] + 1` LAST. JSFX loads when `[g]` changed and `[g+1] == smp_tok`; a same path
  already loaded is not reloaded. JSFX publishes `[g+3]` status (0 empty, 1 loading, 2 ready, 3 failed, 4 truncated),
  `[g+4]` frames loaded, `[g+5]` samplerate, `[g+6]` channels, `[g+7]` frames of the whole file, `[g+504]` path
  version, `[g+505]` length, `[g+506..]` chars of the path it PLAYS. **The generator is the authority**: its path is
  saved in `@serialize` (`smp_ser`, then 1024 chars), the window only re-reads it.

### 7.3 Writing values from Rust (the shape law — measured 2026-10-08)
For a `:log` slider REAPER's `TrackFX_GetParam/SetParam` speak `h = ln(v)`; for `:sqr`, `h = sign(v)·√|v|`;
the normalized is linear in h: `n = (h(v) − h(min)) / (h(max) − h(min))`. **SetParam(440) on a `:log` slider sets
e^440 Hz** (and NaN is accepted and saved as "?"). Therefore: shaped sliders = write `SetParamNormalized(n)`,
read `GetParamNormalized` and invert. Shaped: `:log` p2, p7, p21, p27, p42; `:sqr` p11, p12, p14, p47, p59, p60,
p62, p64, p65, p67, p69, p70, p72, p74, p75, p77, p78, p80, p81, p83, p84. Everything else (and the whole sequencer,
Notes) is linear: SetParam = raw. Sync enums are written RAW (index), never normalized (range grew 6→7).
`shp` (p98): 0 = old links not converted, 1 = converted, 2 = clean; a fresh instance is set to 2. Tools model:
S/../Tools/fake_params.lua.

### 7.4 OSC pitch model (panel-side; S/SoundGenerator.lua:684-890)
The JSFX only knows Hz (`oscN_freq`) + `oscN_fine`. The panel owns the split NOTE + CENTS: `osc.fine` is a state,
note = round(midi(freq) − fine/100), `freq = 440·2^((note + fine/100 − 69)/12)` (clamped 20..20000 as a safety net).
PITCH changes the note only (`setPitchPos(pos)`: note = round(pos·127 − fine/100), clamped 16..127), FINE changes the
cents only (`setFine`, clamped ±49.9: at 50 the nearest note flips). `reconcilePitch` is the only arbiter: if
Hz − cents is not an integer note (within 1e-6 st) the Hz wins and cents := deviation to the nearest note.
OSC 1 mode **NOTE** (default; PITCH steps by semitone, shows "A3") or **HZ** (`osc.hz`, PITCH continuous, shows
"440.0 Hz"; fine stays as an extra) — stored in the preset and in `P_EXT:CP_FXC_SG_OSC1_PITCH`; no slider.
OSC 2/3: FREE (absolute, like OSC 1 NOTE) or REL (semi −48..48 + cents −100..100 relative to OSC 1's snapped note).
`effectiveFreq(sg, i)` mirrors the JSFX (scale snap included) for display.

## 11. Record.lua (what it is)

change during a pass (both SG and Seq upgrades/retire wait). Session-only arming. Not part of the synth engine.
